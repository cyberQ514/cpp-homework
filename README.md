# C++ 课程作业合集

程序设计课上的三个控制台小程序，用来练 C 语言的基础语法：输入输出、循环、分支、函数和取模。

| 文件 | 内容 |
| --- | --- |
| `prime.cpp` | 输入一个整数，判断它是不是素数 |
| `calculator.cpp` | 输入两个整数和一个运算符，输出四则运算结果 |
| `game.cpp` | 取数游戏：双方轮流取 1~2 个，取到最后一个的人获胜（电脑必胜） |

## 怎么编译

需要 g++（Dev-C++ 自带的就行）。在三个文件所在的目录打开终端：

```bash
g++ prime.cpp -o prime
./prime
```

Windows 上生成的是 `prime.exe`，直接双击或者输入 `prime.exe` 运行。

## 三个程序分别做了什么

### prime.cpp

读入一个整数，判断它是不是素数。小于 2 的直接判否；其余的从 2 开始试除，只需要试到 `t * t <= n`，比从头试到 n 快很多。

### calculator.cpp

先读两个整数，再读运算符，最后按运算符计算。除法和取余之前会检查除数是不是 0；不认识的运算符会提示。

### game.cpp

经典取数游戏。电脑的策略是每轮和你凑成 3：

- 总数不是 3 的倍数时，它先手取走余数，把台面变成 3 的倍数；
- 之后你取 1 它取 2、你取 2 它取 1，最后一手总落在它手上。

所以这是一个**必输局**。想赢只能改规则，比如允许每次取 1~3 个、或者让电脑先手。

## 中文显示乱码怎么办

源码是 UTF-8。程序里已经调用 `SetConsoleOutputCP(65001)`，Windows 下正常编译运行应该能直接显示中文。

如果还是乱码，可以：

- 在终端先执行 `chcp 65001` 再运行；
- 或者把源文件另存为 ANSI/GBK 编码再编译。

## 已知的简化

- 只处理整数，除法是整数除法；
- 输入错了直接退出，没有做循环重试；
- 游戏只支持每次取 1~2 个。

## 可以继续改的地方

- `prime.cpp`：加一个「打印 1~n 之间所有素数」的功能；
- `calculator.cpp`：支持小数、支持连续计算（像真正的计算器那样）；
- `game.cpp`：换成 1~3 个的取法，或者做成多堆石子（Nim 游戏）。
